# Imágenes para Bella Joyería

Este directorio contiene las imágenes utilizadas en el sitio web de Bella Joyería.

## Estructura

```
img/
├── banner.jpg          # Banner principal para la página de inicio
├── perfil.png          # Imagen de la boutique/tienda
└── productos/
    ├── prod1.jpg       # Collar dorado elegante
    ├── prod2.jpg       # Pulsera minimalista
    ├── prod3.jpg       # Anillo con piedra
    └── prod4.jpg       # Aretes brillantes
```

## Descripción de las imágenes

### banner.jpg
- **Uso**: Página principal (index.html)
- **Tamaño recomendado**: 1920x400px
- **Descripción**: Banner elegante mostrando la colección de joyas

### perfil.png
- **Uso**: Páginas index.html y contacto.html
- **Tamaño recomendado**: 400x300px
- **Descripción**: Foto de la boutique o imagen representativa

### productos/
- **prod1.jpg**: Collar dorado elegante - $299.99
- **prod2.jpg**: Pulsera minimalista - $89.99
- **prod3.jpg**: Anillo con piedra - $189.99
- **prod4.jpg**: Aretes brillantes - $459.99

## Notas
- Todas las imágenes deben ser de alta calidad
- Usar fondo blanco o transparente para productos
- Mantener proporciones consistentes
- Optimizar para web sin perder calidad

## Reemplazo
Para usar tus propias imágenes, simplemente reemplaza estos archivos manteniendo los mismos nombres.
